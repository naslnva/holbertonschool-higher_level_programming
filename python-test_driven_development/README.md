# Python Test Driven Development

This directory contains the first Holberton School TDD project:

## 0. Integers addition

- File: `0-add_integer.py`
- Function: `add_integer(a, b=98)`
- Adds two integers
- Floats are casted to integers
- Raises `TypeError` if arguments are not int/float
- Default value of `b` is 98
- Tested with `doctest`
